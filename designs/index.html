Five redesigns

Same content as the live site, five different directions. Open each one and try the hero interaction.

  1. FairwayGolf-inspired. A drive arcs across the hero and lands on the portrait; skills read like a yardage book, the timeline like a scorecard.
  2. CommitUW purple on light. A git rail fills as you scroll, the journey is a branch that forks at UW and merges into DoorDash, skills are contribution grids.
  3. KineticPurple and gold. The name is a variable font that squeezes toward your cursor, skill fluency is shown as type weight, projects scroll sideways.
  4. SignalData-science lab. The name is made of particles you can scatter, skills are a dot plot, the journey sits on a real time axis.
  5. StackQuiet editorial. Each section is a sheet that slides over the last, the portrait opens with a circular reveal, projects preview on hover.
